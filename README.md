# 응급실 번표 관리 앱

**바로 열기:** https://kimgwinil.github.io/er-roster/ (GitHub Pages — 자동 생성(서버 계산)은 제외, 직원 데이터는 [불러오기]로 연 브라우저에만 저장)

응급실 간호사 3교대 번표를 자동 생성하고, 위반·확인 사항을 표시하며, 직접 수정·중간 변동·연차·입퇴사를 반영하는 웹앱입니다.
Vercel에 배포되며 화면은 React(Vite), 자동 생성은 Python 함수(OR-Tools)입니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 근무표 | 번표 표시. 칸을 눌러 직접 수정(수정한 칸은 고정). 위반은 빨강, 확인은 주황, 권장은 점선 테두리. 날짜 머리글을 누르면 그날부터 다시 생성할 기준일로 선택 |
| 확인·위반 | 조건 위반·사람이 확인할 사항·권장 사항 목록. 누르면 해당 칸으로 이동. 불가피한 항목은 메모와 함께 [확인 완료] |
| 급작 휴가·변동 | **병가·경조(상조)·연차(당일)·공가·조퇴**를 직원·기간·사유로 입력. 근무였던 날만 바뀌고(이미 쉬는 날은 유지) 고정됨. **대체 근무 자동 편성**을 켜면 그날부터 다시 짜되 기존 근무를 최대한 유지하고, 바뀐 칸은 초록 표시. 조퇴는 근무 유지 + '조' 표시·확인 항목. **변동 이력** 기록 (엑셀 '변동 이력' 시트) |
| 조건 규칙 | **금지·지향 조건**: **근무 제한**(안 됨)·**근무 지정**(이 근무만)·**조건부 제한**(A 근무면 n일 뒤·전 B 안 됨/만, 예: 주휴·OF 전날 N 불가)·근무 순서(N→휴무→D 등)·횟수(최소·최대)·같은 근무(함께·따로). **특정인 근무조건**: 직원을 고르면 그 사람 조건만 모아 보고 바로 지정. 조건마다 **금지**(반드시) / **지향**(가능하면, 중요도 약·중·강) 선택, 끄기·수정·삭제. **근무 특별조건**: 대상·기간·내용 자유 입력 → 근무표 메모와 확인 항목으로 표시, [규칙으로 만들기]로 자동 생성에 반영 |
| 직원 | 명단·역할(차지/신규/소아차지/소아액팅)·주휴 요일·잔여휴가·직전 근무·가능 근무. **신규 입사**(입사일)와 **퇴사**(퇴사일) 처리 |
| 신청·지정 | 신청오프, **연차·휴가 직접 입력**, 공가, 장기휴가, 근무 지정, 요일 고정, 주휴·OF 조건 제외 기간, 기간 내 최소 휴가 |
| 휴가 잔여 | 주별 시작·사용·종료 잔여. **[전주 대비 적용]**을 누르면 그 주 시작 잔여가 전주 종료 잔여로 확정되어 자동 생성에 반영 |
| 조건 설정 | 기간, 하루 인원, 차지·신규 인원, 연속 근무, 원본 조건 문장 |

## 사용 순서

1. **불러오기**: 병동 조건 엑셀(`번표명단과 조건값`, `번표신청달력` 시트) 또는 저장한 번표 JSON.
2. 개인별 특수 조건을 **신청·지정** / **직원** 화면에서 입력.
3. **자동 생성** → **확인·위반** 탭에서 남은 항목 확인.
4. 중간 변동: 병가·경조·조퇴 등은 **[급작 휴가·변동]**에서 입력하면 대체 근무까지 자동 편성됩니다. 퇴사·입사·연차 등 그 밖의 변동은 입력 후 근무표에서 변동 날짜 머리글을 누르고 **[그날부터 다시 생성]**. 이전 근무와 직접 고친 칸은 그대로이며, [기존 근무 최대 유지]가 켜져 있으면 바뀌는 칸이 최소가 됩니다.
   - 자동 생성 우선순위: **하루 인원** > **소아 구성** > **신청오프** > 우선순위 '낮음' 신청오프 > **차지 3~4명**. 차지 5명을 먼저 허용하고, 그래도 안 되면 '낮음' 신청부터 바꾸며, 하루 인원을 채울 수 없을 때만 신청오프가 빠집니다. [조건 설정]에서 **차지 인원을 신청오프보다 우선**을 켜면 차지 3~4명을 지키려고 신청오프를 근무로 바꿉니다.
   - 색: 노랑 = 신청오프 반영, **형광 분홍** = 신청오프 미반영, **형광 연두** = 근무 조건 위배 (엑셀 내보내기도 같은 색).
5. **엑셀 내보내기**(색·집계·확인 사항·휴가 장부 포함), **저장(JSON)**으로 보관.
6. 다음 달은 **다음 번표 시작**: 마지막 근무와 종료 잔여휴가를 이어받습니다.

## 개인정보

- 입력한 데이터는 사용하는 브라우저(localStorage)에만 저장됩니다. 다른 컴퓨터로 옮길 때는 JSON 파일을 사용합니다.
- 자동 생성 때 서버(`/api/solve`)로는 **이름·메모를 뺀 번호와 조건만** 보내며, 서버는 아무것도 저장하지 않습니다.

## 미리보기 링크 (Claude 아티팩트)

`VITE_PREVIEW=1 npm run build` → `dist-preview/` 를 아티팩트로 게시합니다. 확인 창 대신 바로 진행(되돌리기 가능), 파일 저장은 아티팩트 downloads 기능, 자동 생성(서버)은 꺼짐, 처음 열거나 새 판을 게시하면 `preview-public/sample.json`(실제 번표 데이터 — 저장소에 올리지 않음)을 열고, `preview-public/final.json`(최종 엑셀을 base64로 담은 파일)이 있으면 [최종 번표 엑셀 내려받기] 버튼을 보여 줍니다.

## 개발

```bash
npm install
npm run build          # 타입 검사 + 빌드
npm test               # 검증 엔진 테스트 (SCENARIO_JSON=시나리오.json 지정 시 11월 실데이터 대조)
pip install -r requirements.txt
```

- `api/solve.py` — 자동 생성 엔진 (Vercel Python 함수, 최대 300초)
- `src/rules.ts` — 화면 검증 엔진 (위반·확인·권장)
- `src/conditions.ts` — 금지·지향 조건과 특별조건 (기본 근무 순서 규칙, 이전 형식 변환, 검사)
- `src/leave.ts` — 주별 휴가 장부와 전주 대비 적용
- `src/excel.ts` — 조건 엑셀 불러오기, 번표 엑셀 내보내기
